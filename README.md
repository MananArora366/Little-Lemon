# Little Lemon

This is the backend for the Little Lemon restaurant project, built with Django.

## Current Progress: Modules 1-5 (Core Django Web Framework)

- **Module 1**: Created the `littlelemon` project and `restaurant` app.
- **Module 2**: Created standard function-based views (`web_menu_view`, `web_book_view`) and wired up URL routing.
- **Module 3**: Defined `Menu` and `Booking` models in the database (using SQLite).
- **Module 4**: Implemented template inheritance using a `base.html` skeleton, and injected dynamic content into `index.html`, `menu.html`, and `book.html`.
- **Module 5**: Built a secure HTML form using `forms.ModelForm` for bookings, and configured the Django Admin panel for visually managing database records.

*(Note: Advanced Django REST Framework API code is also present in this repository, which will be utilized when starting the subsequent APIs course.)*
